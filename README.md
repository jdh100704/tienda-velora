# 🛒 Velora — Plataforma E-commerce

Velora es una tienda en línea moderna desarrollada con **Next.js** y **Supabase**, que incluye catálogo interactivo, carrito de compras en tiempo real y registro de pedidos.

## 🚀 Tecnologías Utilizadas

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Backend & Base de Datos:** Supabase (PostgreSQL)
- **Librerías:** `lucide-react` (Iconos)
- **Despliegue:** Vercel

## ✨ Características

- 📦 **Catálogo Dinámico:** Visualización y filtrado de productos.
- 🛒 **Carrito de Compras:** Gestión de productos en tiempo real con cálculo automático de totales.
- 💳 **Checkout Directo:** Procesamiento de compras con persistencia en Supabase.
- 📱 **Diseño Responsive:** Adaptado a dispositivos móviles, tablets y escritorio.

## 🛠️ Instalación Local

```bash
# Clonar el repositorio
git clone [https://github.com/jdh100704/tienda-velora.git](https://github.com/jdh100704/tienda-velora.git)

# Entrar a la carpeta
cd tienda-velora

# Instalar dependencias
npm install

# Iniciar en entorno de desarrollo
npm run dev
